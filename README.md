# Hive Immunity System

A digital immune system for IoT devices. Smart devices detect attacks with a tiny
on-device model, quarantine themselves, and share signed **vaccines** ("block this
sender") so their neighbours block the attacker before it reaches them. Dumb devices that
cannot run our code are protected by the router/gateway, which quarantines them.

Peer-to-peer, offline, no cloud.
